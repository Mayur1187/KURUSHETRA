# JalSangam AI — Autonomous Water-Sharing Dispute Mediation Platform

**JalSangam AI** is a full-stack digital mediator platform designed to resolve water allocation disputes among farmers sharing limited irrigation and canal water resources.

Rather than acting as a simple allocation calculator, JalSangam AI serves as a **neutral autonomous digital mediator** (`JalNyay AI`). It detects water shortages and scheduling overlaps, evaluates farmer urgency and historical fairness, represents farmer preferences via digital negotiation agents, processes natural-language objections, dynamically injects machine-enforceable constraints, recalculates revised allocation schedules, provides factual plain-English explanations, and records binding immutable agreements.

---

## 🌟 Core Product Paradigm

$$\text{Detect} \longrightarrow \text{Reason} \longrightarrow \text{Allocate} \longrightarrow \text{Negotiate} \longrightarrow \text{Object} \longrightarrow \text{Recalculate} \longrightarrow \text{Explain} \longrightarrow \text{Agree} \longrightarrow \text{Record}$$

## 🛠️ Architecture & Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Axios, React Router v6.
- **Backend**: Python 3.13, Flask 3.0, Flask-CORS.
- **Database**: Supabase PostgreSQL + Zero-Dependency In-Memory Local Database Fallback (`mock_db.py`).
- **AI Mediation Layer**: Google Gemini API / OpenAI API with fallback rule parser for natural language objection parsing and agent dialogue generation.
- **Deterministic Engine**:
  - **Conflict Detection Engine**: Detects water shortages, critical minimum requirement deficits, and canal delivery time overlaps.
  - **Constraint Engine**: Enforces available water limits, farmer minimum requirements, canal flow rates, and dynamic objection constraints.
  - **Allocation Engine**: Deterministic priority-weighted allocation algorithm:
    $$\text{Priority Score} = \text{Urgency} \cdot 0.30 + \text{Crop Criticality} \cdot 0.25 + \text{Historical Disadvantage} \cdot 0.20 + \text{Fairness Credit} \cdot 0.15 + \text{Deficit} \cdot 0.10$$
  - **Temporal Fairness Engine**: Multi-cycle tracking of satisfaction ratios ($Satisfaction = \frac{Allocated}{Requested}$) and accumulation of **Sacrifice Credits**.
  - **Canal Scheduler**: Converts water allocations into non-overlapping delivery time slots along the canal network.

## 🚀 How to Run Locally

### 1. Start the Flask Backend Server (Port 5000)

```bash
cd backend
pip install -r requirements.txt
python app.py
```

*The backend will start at `http://localhost:5000`.*

### 2. Start the React Frontend Application (Port 3000)

```bash
cd frontend
npm install
npm run dev
```

*Open your browser and navigate to `http://localhost:3000`.*

## 🎯 Demo Hackathon Scenario

Prepopulated out-of-the-box with the official hackathon scenario:

- **Available Water**: 10,000 Liters (Canal Capacity: 2,500 L/hr)
- **Total Requested Demand**: 15,000 Liters (**Shortage**: 5,000 Liters)
- **Farmers**:
  - **Farmer A (Wheat)**: Requested 5,000 L, Min 3,000 L, Urgency 4. High flexibility.
  - **Farmer B (Vegetables)**: Requested 4,000 L, Min 2,500 L, Urgency 4. Morning preference. *Demo Objection: "I cannot irrigate after 2 PM because workers are unavailable."*
  - **Farmer C (Sugarcane)**: Requested 6,000 L, Min 4,000 L, Urgency 5. Critical crop stage.

### Demo Walkthrough:
1. Navigate to **Dashboard** (`/dashboard`) or **Conflict Center** (`/conflict-center`). Notice the 5,000 L shortage alert.
2. Click **START AI MEDIATION**.
3. In the **Negotiation Room** (`/negotiation-room`), view Round 1 initial allocation proposal generated by JalNyay AI.
4. Click **Submit Objection & Trigger AI Renegotiation** (submitting Farmer B's objection).
5. Watch the AI extract the hard constraint (`TIME_AVAILABILITY`, latest end `14:00`), recalculate allocations, shift delivery slots, and finalize a 100% binding consensus agreement (Round 2).
6. Click **View Final Agreement** (`/agreement`) to inspect the final contract, fairness breakdown, and complete audit trail log.

## 🔌 API Endpoints

- `GET /api/health` — Health check
- `GET /api/farmers` — Get registered farmer profiles
- `POST /api/farmers` — Add new farmer profile
- `GET /api/water-resource` — Get available water supply & canal flow rate
- `POST /api/water-resource` — Update available water parameters
- `POST /api/conflicts/detect` — Trigger conflict detection engine
- `POST /api/mediation/start` — Start AI mediation workflow & compute Round 1 proposal
- `POST /api/negotiation/object` — Process natural language objection & trigger renegotiation
- `GET /api/agreement/:id` — Retrieve final finalized agreement contract
- `GET /api/audit-logs/:id` — Retrieve full step-by-step audit trail
